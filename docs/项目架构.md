# 文匠 DocSmith — 项目架构

## 一句话

基于 **pdfcn + TanStack Start** 的 PDF 文档学习与生成平台：用 JSON（DocSpec DSL）描述文档 → 渲染为 pdfcn React 组件树 → Takumi WASM 引擎输出矢量 PDF。浏览器无头、无 Puppeteer，中文字体内嵌可选可复制。

## 技术栈

| 层 | 选型 | 说明 |
|----|------|------|
| 全栈框架 | TanStack Start 1.168（Vite 8 插件） | 文件路由 + SSR + server functions |
| PDF 组件 | pdfcn（shadcn registry 拉取源码） | 24 组件 + 9 主题 + 10 模板，源码归项目所有 |
| 渲染引擎 | takumi-pdf 0.14.3（Rust→WASM） | HTML/CSS→PDF，Node 直跑，返回 Uint8Array |
| 校验 | zod 4 | DSL 浅校验（类型层手写支持递归） |
| 样式 | Tailwind 4（脚手架保留）+ 内联设计令牌 | 站点 UI 为新粗野主义风 |

## 渲染管线

```
Playground JSON
      │ zod 校验 (DocSpecSchema)
      ▼
generatePdf (TanStack server function, src/lib/pdf/api.ts)
      │
      ▼
dslToReact() (src/lib/pdf/dsl-to-react.tsx)
  20 种节点 → pdfcn 组件映射；主题经 PdfcnThemeProvider 注入
      │
      ▼
renderDocSpec() (src/lib/pdf/server-renderer.ts)
  · 共享 PdfRenderer 单例（WASM 实例 + 字体跨请求复用）
  · 项目内字体启动注册: NotoSansSC Regular/Bold(.otf, fonts/ 目录)
  · 远程图片预取 → images 选项
  · viewport 单页 / A4 分页 + 页眉页脚 + 书签 + 元数据
      │
      ▼
矢量 PDF (Uint8Array → base64 → 前端 iframe 预览 / a 标签下载)
```

## 关键设计决策（踩坑记录）

1. **字体单例**：`PdfRenderer` 与字体在进程级注册一次；`render()` 每次传字体描述符对象（不能传名字符串，会被当 URL fetch 报错）。
2. **NODE_ENV 陷阱**：本环境 `NODE_ENV=production` 会让 npm 静默跳过 devDependencies——安装一律 `NODE_ENV=development npm i --include=dev`。
3. **JSX 运行时**：bundle 以 development JSX 编译，生产运行时入口固定 `process.env.NODE_ENV="development"`（React jsx-dev-runtime 在 production 下导出 undefined，会 SSR 500）。
4. **递归 DSL 类型**：zod 不适合直接表达递归 union → 类型层手写 interface，运行时浅校验 + 渲染层兜底。
5. **pdfcn 差异**：Section 无 title prop（DSL 层组合 Heading）；KeyValue 的 key 是 `key/value/valueColor`（DSL 用 label/color 映射）；PageFooter 无 children（页码经 rightText 传入）。
6. **横向导入**：`@/` 别名在 tsconfig paths + vite alias 双处配置（package.json `#` imports Vite 不识别）。
7. **单页裁剪**：viewport 固定高度内容溢出直接裁剪——证书预设按 794px 高度精确排版。

## 运行

```bash
NODE_ENV=development npm i --include=dev   # 安装（注意 NODE_ENV 陷阱）
npx vite dev --port 3000                    # 开发
npx vite build                              # 构建（NODE_ENV=development）
PORT=5177 node scripts/prod-server.mjs      # 生产（systemd: nami-web-docsmith）
```
