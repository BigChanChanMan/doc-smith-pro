# 文匠 DocSmith — DSL 节点 / pdfcn 组件手册

> 每种 DSL 节点对应一个 pdfcn 组件。学会写 JSON 就等于学会了 pdfcn。
> 全部 20 种节点均可在 Playground 与组件画廊中实时渲染验证。

## 文档结构（DocSpec）

```jsonc
{
  "theme": "modern",              // 9 套主题之一
  "page": { "size": "a4", "margin": 48, "landscape": false },
  "viewport": { "width": 302 },   // 单页模式（小票/证书），与 page 二选一
  "metadata": { "title": "文档标题", "author": "作者", "lang": "zh-CN" },
  "outline": true,                // 由 heading 自动生成 PDF 书签
  "header": { "title": "页眉标题", "subtitle": "副题", "variant": "minimal" },
  "footer": { "left": "落款", "pageNumbers": true, "pageNumberFormat": "cjk-decimal" },
  "body": [ /* 节点数组，见下表 */ ]
}
```

## 节点速查表

| 节点 type | pdfcn 组件 | 能力要点 |
|-----------|-----------|---------|
| `text` | `<Text>` | variant 七档字号(xs→3xl) · weight 四档 · align · color(主题色名或任意CSS色) · italic · decoration · transform · noMargin |
| `heading` | `<Heading>` | level 1-6 排印尺度 · align · color · weight · tracking 字距 · 自动进书签 |
| `link` | `<Link>` | href 生成可点击 PDF 注释 · default/muted/primary 三态 |
| `alert` | `<PdfAlert>` | info/success/warning/error · title · showIcon · showBorder |
| `badge` | `<Badge>` | default/primary/success/warning/destructive/outline · sm/md/lg |
| `divider` | `<Divider>` | solid/dashed/dotted · label 居中文字 · color |
| `page-break` | `<PageBreak>` | 强制分页 |
| `stack` | `<Stack>` | 纵向堆叠 · gap(none→xl) · align |
| `section` | `<Section>` | 小节容器（DSL 的 title 自动渲染为 Heading+Section 组合）· variant(callout/highlight/card) · border · accentColor |
| `card` | `<PdfCard>` | default/bordered/muted · padding sm/md/lg |
| `keep-together` | `<KeepTogether>` | 内部整体不分页（break-inside: avoid） |
| `key-value` | `<KeyValue>` | items[{label,value,color}] · size sm/md/lg |
| `data-table` | `<DataTable>` | columns[{key,header,align,width}] · rows · footer 合计行 · stripe 斑马纹 · size compact · variant grid/line/minimal |
| `list` | `<PdfList>` | bullet/numbered/checklist/icon/multi-level/descriptive · items[{text,description,checked,children}] 嵌套 |
| `form` | `<PdfForm>` | 打印留白表单 · groups[{title,layout(single/two/three),fields[{label,hint,height}]}] · variant underline/box/outlined/ghost |
| `graph` | `<PdfGraph>` | SVG 矢量图: bar/horizontal-bar/line/area/pie/donut · 单系列 data[{label,value}] 或多系列 data[{name,data,color}] · showValues/showGrid/smooth/showDots/legend/yTicks |
| `image` | `<PdfImage>` | http(s)/data: 源（服务端自动预取远程图）· fit cover/contain/fill/none · caption 图注 · SVG 矢量嵌入 |
| `qrcode` | `<PdfQRCode>` | value 驱动 · size · color · caption · errorLevel L/M/Q/H |
| `signature` | `<PdfSignatureBlock>` | single/inline 单签(label,name,title,date) · double 双签(signers 二元组) |
| `watermark` | `<PdfWatermark>` | text · opacity · fontSize · angle · position 五方位（页面级悬浮每页重复） |

## 主题（9 套）

professional（衬线标题·正式） / modern（Helvetica·冷灰紫） / minimal（Courier·极简） / executive（深海军蓝·董事会） / corporate（蓝灰 Lato·稳重） / elegant（奶油金·编辑风） / vivid（紫 Nunito·活泼） / forest（墨绿·自然） / blueprint（深蓝青·工程图纸）
